# Ferry Times

Timetables for the island ferries, from the command line or from Python.

## Install

```bash
# from the project folder
pip install .
```

## Usage

### From the command line

```bash
ferrytimes --from Oban --to Craignure
```

### From Python

```python
from ferrytimes import next_sailing
```

## Contributing
